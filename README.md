# AI Projects

Portfolio of agentic AI builds — Python, FastAPI, Pydantic. Proof-of-skill companion to the [applied-ai](https://github.com/vishal-jadeja/applied-ai) notes repo: every project exists to make a set of concepts undeniable in an interview.

## Layout

```
AI Projects.md          hub / index
PLAN.md                 project plan (build order + priorities)
INTERVIEW-QUESTIONS.md  Q&A bank on the projects' concepts
<project-name>/         one directory per project (created when started)
```

## Method

Theory first in applied-ai, then build here. Each project ships with a README that explains the problem, the trade-offs taken, the failure modes handled, and metrics — written so it doubles as the interview story.

## Stack

Python 3.12+, FastAPI, Pydantic v2. Tracing/evals layered in as projects mature.
